# BhoomiX

BhoomiX is a farming companion built with React, TypeScript, Vite, Tailwind CSS, shadcn/ui, and Supabase.

## Run locally

```sh
npm install --legacy-peer-deps
npm run dev
```

## Production build

```sh
npm run build
```

The built site is written to `dist/` and can be deployed to any static hosting provider. Set the `VITE_SUPABASE_*` variables in your hosting provider before deploying.
